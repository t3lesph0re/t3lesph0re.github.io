Misconfiguration -- someone set a permission wrong
Excess Privilege -- a token, bit, or group that hands you more than it should
Credential Exposure -- secrets left in files, memory, history, configs
Unpatched Code -- kernel or service exploit
Trust Abuse -- you insert yourself into a path something trusts
