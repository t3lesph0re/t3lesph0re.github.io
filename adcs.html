--- layout: default title: "AD CS abuse" ---
Active Directory Certificate Services (AD CS) is Windows' built-in PKI. It issues X.509 certificates for authentication, encryption, and code signing. When misconfigured, it becomes a domain escalation and persistence mechanism. The ESC classification comes from SpecterOps' "Certified Pre-Owned" research by Will Schroeder and Lee Christensen (2021).
